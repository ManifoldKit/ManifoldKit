# TrappingConstructAuditTest — path-based allowlist for
# fatalError / assertionFailure / precondition / preconditionFailure.
#
# Format: one fingerprint per line, of the form
#   <relative path under Sources/>:<trimmed source line>
#
# - Empty lines and `#`-prefixed lines are ignored.
# - Entries must match the audit's fingerprint EXACTLY (the line content
#   after trimming leading/trailing whitespace).
#
# Every entry below gates a value that is fixed ONCE, at object
# construction, by the calling code — never a value that can change during
# the process's lifetime after the guarded code path was already reached
# safely. That is the dividing line this audit enforces (see the class doc
# comment in TrappingConstructAuditTest.swift): a construction-time
# wiring/config mistake has no meaningful "recovery" beyond "the object
# can't do its job," so trapping at the call site that built it is more
# debuggable than deferring to a later, harder-to-trace failure. A value
# that *can* legitimately flip after construction (like
# URLSessionProvider.networkDisabled, fixed in this same PR) must not be on
# this list — it must have a real recoverable path instead.
