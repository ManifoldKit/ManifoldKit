Systematic audit for code that exists but is not wired up: read paths with no writer, seam-only
ports, ignored config, orphan events, stubs behind real-looking APIs, and doc-claimed capabilities
the code cannot deliver.

**Method.** 30 finder agents (one per source module + 6 cross-cutting lenses: config flow, orphan
events, DI reachability, docs-vs-reality, UI affordances, persistence round-trips), every finding
passed through two-stage adversarial verification (stage 1: prove-it-wired against Sources/, Tests/,
Example/, scripts/, trait- and platform-gated paths, and the local companion/consumer repos
manifold-llama, manifold-mlx, manifold-eval, basechat; stage 2: independent refuter hunting
non-obvious wiring and classifying accidental gap vs documented deliberate seam). 77 raw findings →
75 deduped → **54 confirmed inert/partial + 21 deliberate seams, 0 refuted**.

**Caveat.** Spot-checking showed individual claims can overstate (e.g. "no consumer ever reads
`.phase`" missed an internal writer-side read in `GenerationQueue`). Every fix PR re-verifies its
findings against HEAD before coding; findings that turn out wired are dropped and noted in the PR body.

**Tracking.** At audit time, only finding 51 (resumable-runs flag) had open-issue coverage
(#1957 Tier 4). Merged PRs #2075/#2077/#2078 fixed a different, earlier batch of inert-surface
findings — zero overlap with this list.
